# Return

**No distribuir mientras la máquina esté activa**

**Créditos al creador de la máquina: MrR3boot**

Return es una máquina que presenta las siguientes configuraciones:

## Acceso Inicial

1. Acceso no autenticado a una página de configuración para una impresora -> Modificación del servidor de administración
2. Re-uso de contraseñas

## Escalada de Privilegios

1. Privilegios demasiado elevados para el usuario -> Abuso del grupo Server Operators.
