# Timelapse

**No distribuir mientras la máquina esté activa**

**Créditos al creador de la máquina ctrlzero**

Timelapse es una máquina Windows que presenta la siguiente configuración:

### Acceso Inicial

1. Acceso anónimo a lectura se shares SMB
2. Lectura de archivos delicados .zip
3. Contraseñas débiles

### Escalada de Privilegios 

1. Pertenencia a grupos privilegiados para leer contraseñas en texto claro.
